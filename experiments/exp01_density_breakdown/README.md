# Exp01: 密度の情報崩壊点の推定（Density Breakdown Curve）

## 目的

卒業論文の中核的知見——「低密度集落群において密度の寄与は5%台に留まり、
相転移特性（W_trans, γ）が識別を支配する」（6地点・探索的）——を、
全球層化サンプル N≈10,000 で**密度水準の連続関数として**一般化する。

「低密度は d < 0.03」という先験的しきい値を仮定する代わりに、
**密度の識別寄与が崩壊する点 d\* を推定結果として得る**。

## 仮説

- H1: 密度の識別寄与（leave-one-out 距離減少率）は、密度水準が下がるにつれ
  一様基準（後述）を下回る水準へ単調に低下する
- H2: 同じ領域で相転移ダイナミクス（γ, W_trans）の寄与は一様基準以上を維持
  または上昇し、ある密度 d\* で寄与の主役が交代する（量 → ダイナミクス）

## データ

- global_v2 全球層化サンプル（WSF2019 5分位 × 22サブリージョン、10,723地点設計、
  処理済み 10,555 地点、percolation 曲線あり 10,068 地点）
- 取得元: WSL `~/dev/OS/251229_repro/outputs/`（2026-07-08 転送）
  - `metrics_global_v2_batch{0..8}.csv`: 基本指標（d, Λ̄, s_Λ, Δα ほか）+ メタデータ
  - `real_world_global_v2/<lat>_<lon>/percolation.csv`: G(r) 曲線
  - `real_world_global_v2/<lat>_<lon>/mfa_spectrum.csv`: MFA スペクトル

## OS 特徴ベクトル（論文 表1 の9次元）

`[d, Λ̄, s_Λ, r_crit, Δα, W_trans, γ, ΔD, S_α]`

- d, Λ̄, s_Λ, Δα: metrics CSV から（s_Λ = lacunarity_slope = β）
- **r_crit: 表1定義 argmax_r dG/dr** を percolation 曲線から再導出
  （旧実装の G=0.5 交差は使わない）
- γ: r_crit（最大勾配点）における dG/dr
- W_trans: r|G=0.9 − r|G=0.1
- ΔD = D0 − D2, S_α: mfa_spectrum から

## 分析手法

1. **感度分析（論文 §5.4 と同一の定義）**: 対象集合の9次元 z-score 空間での
   平均ペアワイズ距離を分離度とし、各特徴を除去したときの距離減少率(%)を
   その特徴の寄与とする
2. **移動窓**: 全地点を密度 d で昇順ソートし、窓幅 W=800、ステップ 250 の
   移動窓ごとに感度分析を実施。x軸 = 窓内の中央値密度
3. **一様基準**: 9特徴が無相関なら任意の1特徴除去による平均距離減少率は
   1 − √(8/9) ≈ **5.72%**。これを下回る特徴は「他の特徴と冗長＝固有情報が乏しい」、
   上回る特徴は「固有の識別情報を持つ」と解釈する
   （卒論の「密度5%台 vs γ約7%」はこの基準に照らすと、
   密度=基準以下（冗長）、γ=基準以上（固有）と読める）
4. **d\* の推定**: (a) 密度の寄与が一様基準を下回る点、
   (b) 密度の寄与とダイナミクス寄与（γ, W_trans の平均）が交差する点、の両方を報告
5. **不確実性**: 窓内ブートストラップ（B=100、地点の再抽出）で95%CI。
   頑健性チェックとしてサブリージョン単位のブロックブートストラップ
   （空間自己相関対策）を実施

## 除外規則

- percolation 曲線が存在しない地点（建物ノード不足等）: 9次元が揃わないため除外
- 特徴に NaN が残る地点: 除外（件数を報告）

## 制約・注意
